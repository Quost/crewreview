# Interface

Can someone actually use this: with one hand, on a phone, in the sun, in a hurry, with a screen reader?

Look for:

- States that are missing: loading, empty, error, offline, very long text, many items.
- Accessibility: missing labels or alt text, focus order, keyboard traps, color as the only signal, contrast, touch targets.
- Light and dark themes: hard-coded colors, text that disappears on one of them.
- Layout: overflow on small screens, fixed widths, content hidden behind keyboards or notches.
- Text: strings not translated where the project translates, wording that blames the user, unclear actions.
- Destructive actions without confirmation or undo.
- Consistency with the components and patterns the project already uses.

Cite the component file and line.
